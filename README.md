# swordsaintlancelot.github.io

Personal portfolio. Static site generated by a small Python script.

## Stack

- **Jinja2** templating + **PyYAML** for content
- ~50-line `build.py` renders templates against `data.yaml` into `docs/`
- GitHub Actions runs the build on every push to `main` and deploys `docs/` to GitHub Pages

No runtime Python — the visitor always sees plain HTML served from the GitHub Pages CDN.

## Project layout

```
build.py                       # the generator
requirements.txt               # jinja2, pyyaml
data.yaml                      # ALL content lives here — edit this to update the site
templates/
  base.html                    # shared <head> / footer
  index.html                   # composes sections
  sections/*.html              # one file per page section
static/
  styles.css                   # minimalist academic styling
  resume.pdf                   # (optional — drop in and uncomment in data.yaml)
  images/                      # headshot, project thumbnails, etc.
docs/                          # build output (gitignored — CI produces it)
.github/workflows/deploy.yml   # build + deploy to GitHub Pages
```

## Local development

```bash
pip install -r requirements.txt
python build.py
python -m http.server -d docs 8000
# open http://localhost:8000
```

Edit `data.yaml` → re-run `python build.py` → refresh.

## Deployment

1. Push to `main`.
2. In GitHub repo settings, under **Pages**, set **Source = GitHub Actions**.
3. The workflow builds and deploys automatically. Site goes live at
   `https://swordsaintlancelot.github.io/`.
